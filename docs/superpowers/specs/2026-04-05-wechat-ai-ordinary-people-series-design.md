## 第1篇设计

### 基本信息

- **标题：** AI时代，普通人的杠杆在哪里
- **目标读者：** B（有副业/创业意愿的技术人）+ C（非技术普通人，通过转发触达）
- **文章类型：** 框架型分析文
- **目标字数：** 约3000字
- **核心论点：** AI是有史以来最大的新杠杆，普通人的入口在第三四层，具体路径是知识输出或行业专家工具

### 结构设计

#### 一、开篇 + 纳瓦尔杠杆论（约400字）

- 一句话介绍纳瓦尔（照顾非技术读者）
- 展开三种杠杆：劳动力、资本、代码/媒体
- 点明：代码和媒体是普通人最可触碰的两种杠杆
- 抛出核心问题：AI来了，普通人的杠杆入口在哪？

#### 二、AI产业链四层（约600字）

| 层级 | 代表 | 门槛 |
|---|---|---|
| 硬件与基础设施 | 英伟达、华为 | 极高，资本密集 |
| 大模型与平台 | OpenAI、字节、百度 | 极高，顶尖人才 |
| AI应用与工具 | 各类Agent、行业软件 | 中等，有机会 |
| 使用AI工具 | 普通用户、创业者 | 低，入口最宽 |

- 每层用具体现实感的描述说清楚门槛
- 结论：第一二层是顶尖人才和大资本的战场，第三四层才是普通人的机会所在

#### 三、路一：知识输出（约800字）

- 为什么现在是窗口期：AI发展快，普通人焦虑感强，素材和受众都不缺
- 凯文凯利1000粉丝理论：1000个真粉丝 × 每人年消费$100 = $100,000年收入（2008年提出，今天更容易实现）
- 案例：缸中之脑，一个月从0到10000粉，展开讲做法
- AI如何具体加速每个环节：选题、内容生产、数据分析
- 这条路的上限和难点（不回避：竞争激烈，从0到1000积累不容易）
- 一句话定性：**这条路的本质是做自媒体，AI帮你降低门槛、提高速度**

#### 四、路二：行业专家工具（约800字）

- 为什么这是蓝海：程序员不懂行业痛点，行业专家不懂技术——AI弥合了这个鸿沟
- 案例：CrossBeam — 加州律师Mike Brown，6天赢Anthropic黑客松冠军，打败500名开发者（2026年2月）
  - 解决什么痛点：加州ADU建筑许可90%+首次被拒，大量时间耗在修改文件
  - 如何构建：Claude Opus 4.6 + Next.js + 6天
  - 结果：原本数周的流程，20分钟出方案
- 普通人切入的关键原则（来自草稿）：
  - 有真实行业痛点
  - 建立行业知识库
  - 流程化、pipeline固化专家知识
  - 可验证，降低AI不确定性
  - 用简单技术栈
  - 工具可独立运行，不做多租户系统
- 这条路的门槛和难点：产品化仍有工程门槛，但比以前低了很多
- 一句话定性：**这条路的本质是把专业知识变成可以scale的产品**

#### 五、你适合哪条路（约300字）

简短自检框架：
- 你擅长表达、喜欢和人互动 → 知识输出
- 你在某个行业有深度专业知识 → 行业专家工具
- 两条路不互斥，但需要不同的时间投入模式

#### 六、结尾 + 系列预告（约200字）

- 纳瓦尔的杠杆论收尾：问题不是"有没有机会"，而是"你选哪条路"
- 系列预告：下一篇讲知识输出具体怎么做，第三篇讲行业专家工具具体怎么做
