## 文章一：掘金版（干货清单结构）

**文件名：** `raw_docs/juejin-mindset-01.md`
**标题：** 善用AI的三个心法：为什么资深工程师可能不如你用得好
**受众：** 掘金技术社区，初学者为主，部分技术人群
**风格：** 结构清晰，可截图收藏，干货感强

### 结构

| 段落 | 内容 |
|------|------|
| 开篇 | 回顾两篇：做什么（杠杆篇）+ 怎么做（理财知识库实例）→ 但心态没转变，工具也用不好 |
| 心法一 | 把AI当员工，你是老板：分配任务、把握大局、适时audit，而不是亲力亲为或逐行review |
| 心法二 | 不断challenge，追求完美：AI缩短想法到实现的距离，你可以更高标准打磨用户体验和架构 |
| 心法三 | 小步迭代逼近完美：测试驱动闭环，先想清楚解决什么痛点，可测量地一步步逼近完美 |
| 初学者加餐 | 行业知识是壁垒；从简单项目做起；学够用的开发基础即可 |
| 结尾 | 起步清单（可截图收藏） |

### 核心心法修正
- 心法三不是"别求完美"，而是"用小步迭代逼近完美"——AI缩短了想法到实现的距离，可以反复验证、不断打磨。

## 文章二：公众号版（叙事结构）

**文件名：** `raw_docs/wechat-mindset-01.md`
**标题：** 你公司来了个超强员工，但你还在自己干
**受众：** 微信公众号「老奥杂说」读者，普通人/非开发者为主
**风格：** 叙事代入感强，情绪共鸣，适合转发传播

### 结构

| 段落 | 内容 |
|------|------|
| 开场故事 | 你公司来了个超强新员工，能写代码查资料出方案——大多数人的反应是继续自己干 |
| 回顾前两篇 | 前两篇告诉你能做什么、以及一个真实案例，但你可能仍然在"用户模式"里 |
| 用户模式 vs 老板模式 | 具体行为对比：给细节太多/给方向；自己去改/让AI自己解决；逐行review/把握方向 |
| 老板模式三个动作 | 分配任务 → 适时audit → challenge结果追求完美（迭代是逼近完美的路径，不是将就） |
| 初学者特别说 | 不懂技术不是障碍，行业经验才是AI最需要的；大胆给方向，不要怕犯错 |
| 结尾 | 回扣开场故事：这个员工一直在等你给它真正的任务 |
