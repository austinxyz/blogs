# Claude 初学者付费直播课 — 课程设计文档

**日期：** 2026-05-16
**形式：** 付费直播课（直播后录播继续销售）
**规模：** 2 节 × 2 小时

---

## 目标学员

- **A 类：** 完全不懂 AI 的职场人，想用 AI 提效但不知从何下手
- **B 类：** 已在使用 ChatGPT / Kimi，想升级到 Claude

两类学员共存，起点从零开始，节奏适中——A 类能跟上，B 类不觉得无聊。

---

## 课程主张

学完两节课，学员能用 Claude 完成三件事：
1. **管理信息流**：用 Cowork 处理邮件→调研→报告→发送的日常工作流
2. **沉淀个人知识**：用 Claude Code（不写代码）搭建 LLM 知识库
3. **快速输出成果**：用 Skills（ppt-master）把知识库转化为汇报 PPT

---

## 教学方法

**概念 + 演示** 结合，每个模块：
- 5–10 分钟讲清楚"为什么"（PPT 概念页）
- 20–40 分钟屏幕共享实操演示
- 虚拟场景贯穿，不用真实数据

---

## 演示主线逻辑

```
管理信息流（Cowork 邮件流）→ 沉淀知识（Code + 知识库）→ 输出成果（Skills + PPT）
```

## 需要提前准备的演示素材

### Cowork 演示
- 一封虚拟客户询盘邮件（伪造场景）
- Cowork 工作流配置（邮件触发 → 调研 → 报告 → 发送）
- 预期输出报告样本

### Claude Code 演示
- 知识库原始素材（3–5 篇文章或笔记）
- Claude Code 自然语言指令脚本
- 完成后的知识库成品展示

### Skills 演示
- 以知识库输出为 PPT 输入
- ppt-master 模板选择（wiki-invest-detailed 或 simple）
- 最终 PPT 成品展示
