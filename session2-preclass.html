1
安装 Claude Code

Claude Code 是在“终端”里用的 AI 助手，能直接帮你读写电脑上的文件。选你的系统，把命令复制到终端里运行即可——不需要先装 Node.js，这条命令会自动搞定一切。

开始菜单搜索 PowerShell 并打开，粘贴这行回车：

Windows · PowerShell
irm https://claude.ai/install.ps1 | iex

按 Command + 空格，输入 终端 或 Terminal 打开，粘贴这行回车：

Mac · 终端
curl -fsSL https://claude.ai/install.sh | bash

装完后（两个系统通用）

  1. 在同一个窗口输入 claude 回车 → 启动
  2. 第一次会让你登录，按提示用浏览器登录你的 Claude 账号
⚠️ 需要 Claude Pro（每月 $20）；已经是 Pro 就不用再付费。订阅：claude.ai/settings/billing
2
安装 Obsidian

Obsidian 是一个免费的笔记软件，能把一堆文件变成“知识图谱”，看清条目之间的关联。课上我们用它来看知识库；现在先装好。

打开 obsidian.md 下载

点 Download，选你的系统（Windows / Mac）安装。免费版就够用，不用注册、不用付费。

3
用 Obsidian 打开我的财富知识库

这是最关键的一招：用一个已经存在的文件夹建 vault。课上和现在预习，都是打开现成的文件夹，不是从空白开始。先拿我的财富知识库练一遍。

💡 Vault（保险库）= 一个普通文件夹。Obsidian 只是换种方式打开文件夹来看里面的笔记，不会改动你的文件。

① 下载我的财富知识库

点击下载财富知识库 ZIP

下载后解压，得到一个文件夹（里面有 wiki/、raw_material/ 等）。建议解压到桌面，方便找。

② 用 Obsidian 打开这个文件夹

打开 Obsidian → 启动页点 Open folder as vault
（如果已经在某个 vault 里：点左下角 vault 名字 → Manage vaults → Open folder as vault）

选中刚解压出来的财富知识库文件夹 → 打开

左侧就会出现一篇篇 wiki 条目，点开任意一篇就能看。

③ 打开 Graph View 看知识关联图（课上重点）

左侧工具栏点那个“圆点连线”图标（Open graph view）
会看到所有笔记和它们之间的连线——这就是“跑了 20 篇之后”的完整知识库
💡 课上你自己建的库，也是同样用 Open folder as vault 打开。会这一招就够了。
4
VS Code / GitHub选做

这两个不是必须的——课上演示不依赖它们。对技术感兴趣、想把知识库管理得更专业，可以装。

VS Code — 看 / 改 AI 生成的文件

  1. 下载安装：code.visualstudio.com
  2. 用法：菜单 File → Open Folder → 选你的知识库文件夹；左边文件树点开就能看/改，Ctrl+S（Mac Cmd+S）保存
  3. 入门教程：官方 10 分钟视频

GitHub — 备份 + 分享你的知识库

  1. 注册账号：github.com
  2. 最简单：装 GitHub Desktop（图形界面，不用敲命令）：desktop.github.com → Add Local Repository 选你的文件夹 → 写说明 → Commit → Push 上云
  3. 入门教程：GitHub Desktop 官方图文
⚠️ 知识库里如果有客户/隐私数据，建私有仓库（Private），或把这些文件放进 .gitignore 不上传。
